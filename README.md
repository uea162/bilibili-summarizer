# B站视频AI总结

浏览器扩展，一键生成 B站视频的 AI 总结。

## 功能

- 自动提取视频字幕（AI字幕 + CC字幕）
- AI 生成结构化总结（视频概要 + 详细总结）
- 总结中的时间戳可点击，直接跳转视频对应位置
- 侧边栏展示，支持拖拽、折叠、暗色模式
- 支持多种 AI 服务商

## 安装

1. 下载本仓库代码
2. 打开 Edge 浏览器，访问 `edge://extensions/`
3. 开启「开发者模式」
4. 点击「加载已解压的扩展」，选择项目文件夹

Chrome 同理，访问 `chrome://extensions/`。

## 配置

点击浏览器工具栏的扩展图标，选择 AI 服务商：

| 服务商 | 说明 |
|--------|------|
| DeepSeek | 推荐，注册送免费额度 |
| 通义千问 | 阿里云，部分免费 |
| 智谱 GLM | GLM-4-Flash 免费 |
| Claude | Anthropic 官方 |
| OpenAI | GPT-4o / GPT-4o Mini |
| 硅基流动 | 开源模型代理 |
| 自定义 | 任何 OpenAI 兼容接口 |

填入 API Key，保存即可。

## 使用

1. 打开任意 B站视频页面
2. 操作栏右侧出现「AI总结」按钮（稿件举报左边）
3. 点击按钮，等待 AI 生成总结
4. 点击总结中的时间戳可跳转到视频对应位置

## 项目结构

```
manifest.json    # 扩展配置
content.js       # 页面注入逻辑（按钮、字幕提取、侧边栏）
content.css      # 样式（B站风格，支持暗色模式）
background.js    # 后台服务（API 调用）
popup.html/js/css # 设置页面
icons/           # 扩展图标
```
